# Contacts.app

This project follows the [Hypermedia Systems](https://hypermedia.systems/) book. It will start as a basic "Web 1.0-style" Multi-Page Application (MPA), in the grand CRUD tradition. 
This application will then be incrementally improved by utilizing hypermedia-oriented library htmx.

However, the book chooses Python with Fask and Jinja2 for it's server-side language and library. I will be using Go, it's standard library, and templ.
